# Trussk

Landing page for **Trussk** — a business that builds AI agents, integrates them into existing workflows, and measures their impact.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build for production

```bash
npm run build
npm run preview
```

Static output is in the `dist/` folder — deploy to Vercel, Netlify, Cloudflare Pages, or any static host.

## Sections

- **Hero** — Value proposition with live dashboard preview
- **Services** — Build agents, integrate workflows, measure impact
- **Process** — Discover → Design & Build → Deploy & Measure
- **Impact** — Metrics and analytics capabilities
- **Contact** — Lead capture form
